# Learning Roadmap

Build the chatbot in small steps:

1. Add a local knowledge source.
2. Parse documents into normalized source objects.
3. Add chunking.
4. Add embeddings.
5. Add vector storage.
6. Add retrieval.
7. Add answer generation.
8. Add chat persistence.
9. Add permission filtering.
10. Add evaluation tests.

Keep each step working before moving to the next.
