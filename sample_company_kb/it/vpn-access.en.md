# VPN Access

Employees use the company VPN when accessing internal systems outside the Bishkek office network. VPN access requires multi-factor authentication.

## Setup

IT provides VPN setup instructions during onboarding. Employees should not share VPN configuration files or one-time codes with anyone.

## Troubleshooting

If VPN login fails, contact IT support and include:

- device name
- operating system
- current location
- exact error message
- screenshot if available

## Access Review

VPN access is reviewed quarterly. Access may be removed for inactive accounts or role changes.
